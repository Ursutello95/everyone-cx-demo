API · MODO CX Trainer

Compatible con Lovable, Bubble, Webflow. Bearer auth · CORS habilitado. La API key de Anthropic se gestiona en el backend Node.js — nunca expuesta al browser.

POST /api/simulate

      

    

    

      
Lovable · Bubble · Webflow
En Lovable usá VITE_API_KEY como env var. El backend Node.js inyecta la Anthropic key — nunca expuesta al browser. En GitHub Pages demo: header anthropic-dangerous-direct-browser-access: true.

      
⚠️ Si la API está bloqueada
401: verificar Authorization: Bearer TOKEN. 403: agregar créditos en console.anthropic.com. 429: rate limit — agregar debounce 500ms. CORS: agregar header anthropic-dangerous-direct-browser-access: true.
